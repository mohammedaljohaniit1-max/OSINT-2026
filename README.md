## الفكرة باختصار

```bash
argus scan example.com              # دومين
argus scan john.doe@company.com     # إيميل
argus scan +966501234567            # رقم هاتف
argus scan johndoe                  # username
```

يتعرّف على نوع الهدف تلقائياً → يشغّل الأدوات والسكربتات المناسبة بالتوازي → يجمّع ويربط النتائج → تقرير موحّد (HTML/PDF/JSON).

## لماذا؟

بدل تشغيل عشرات الأدوات يدوياً (theHarvester ثم amass ثم holehe ثم sherlock...) وتجميع النتائج بشكل ممل — **أمر واحد** يفعل كل شيء.

## المكوّنات الثلاثة

1. **الأدوات الخارجية** — أقوى أدوات OSINT المشهورة وغير المشهورة (theHarvester, amass, holehe, sherlock, maigret, PhoneInfoga, h8mail, shodan...).
2. **سكربتات الإدارة (Orchestrator)** — العقل المدبّر: كشف الهدف، تخطيط المهام، التشغيل المتوازي، الربط، التقارير.
3. **سكربتات خاصة (Native Modules)** — تسدّ الفجوات التي لا تغطيها الأدوات الجاهزة.
