## 📖 ما هذا المشروع؟

`OSINT-2026` (الاسم الكودي **Argus** — العملاق ذو المئة عين) هو إطار عمل استخبارات مفتوحة المصدر (Open-Source Intelligence) مصمّم لمحللي الأمن السيبراني.

بدل تشغيل **عشرات الأدوات يدوياً** وتجميع نتائجها المبعثرة، تكتب أمراً واحداً:

```bash
argus scan company.com
```

فيتعرّف على نوع الهدف تلقائياً، يشغّل **كل الأدوات والسكربتات المناسبة بالتوازي**، يجمّع النتائج ويربطها ويزيل تكرارها، ثم يُخرج **تقريراً احترافياً موحّداً** (HTML / PDF / JSON) مع تقييم مخاطر وأدلّة وتوصيات.

> ⚡ **الميزة الأهم:** يعمل **بكامل طاقته بدون أي مفتاح API**. نعتمد على مصادر عامة مفتوحة + كشط ذكي + محرك بحث محايد (SearXNG). المفاتيح اختيارية تماماً وتُحسّن فقط.

> ⚠️ **الحالة:** المشروع الآن في **مرحلة التخطيط**. هذا الـ README يصف الرؤية الكاملة والبنية والأدوات. للخطة التقنية التفصيلية راجع [`MASTER_PLAN.md`](./MASTER_PLAN.md).

## 🧩 المكوّنات الثلاثة

```
┌─────────────────────────────────────────────────────────────┐
│ 1) الأدوات الخارجية  →  أقوى أدوات OSINT الجاهزة              │
│ 2) سكربتات الإدارة   →  العقل المدبّر (تشغيل/تخطيط/تجميع)     │
│ 3) السكربتات الخاصة  →  الوصفة السرية (تسدّ فجوات الأدوات)   │
└─────────────────────────────────────────────────────────────┘
```

1. **الأدوات الخارجية (External Tools):** أقوى أدوات OSINT المشهورة وغير المشهورة (theHarvester، amass، holehe، sherlock، maigret، PhoneInfoga...). تُستدعى عبر «محوّلات» (Adapters) بواجهة موحّدة.

2. **سكربتات الإدارة (Orchestrator):** النوع الأول من سكربتاتنا. العقل المدبّر: يكتشف الهدف، يخطّط المهام (DAG)، يشغّل بالتوازي، يجمع ويطبّع ويربط النتائج، يولّد التقرير.

3. **السكربتات الخاصة (Native Modules):** النوع الثاني — **الوصفة السرية**. تغطّي الجوانب التي لا تصل إليها الأدوات الجاهزة (استنتاج نمط إيميلات الشركة، محرك Dorks، صيد تسريبات GitHub، صيد الـ Dark Web، الربط الذكي...).

## ✨ ماذا يجمع Argus؟ (التغطية الكاملة)

### 🌐 عند فحص دومين شركة (`argus scan company.com`)
- **معلومات التسجيل:** المالك، تواريخ الإنشاء/الانتهاء، nameservers (RDAP/WHOIS).
- **كل النطاقات الفرعية:** من شهادات SSL + سجلات الشفافية + أدوات التعداد + الأرشيف.
- **سجلات DNS الكاملة:** A/AAAA/MX/NS/TXT/SOA/CNAME/SRV/CAA/DNSSEC.
- **البنية التحتية:** عناوين IP، ASN، الجيران على نفس السيرفر (reverse IP).
- **المنافذ والخدمات والتقنيات:** ما يعمل على الخوادم + بصمة التقنيات + مطابقة الثغرات (CVE).
- **الخوادم الحية:** الحالة، العناوين، لقطات الشاشة.
- **الشهادات (SSL/TLS):** المُصدِر، التواريخ، اكتشاف نطاقات مخفية.
- **أمن البريد:** SPF/DKIM/DMARC/MTA-STS/BIMI + تقييم النضج.
- **إيميلات الموظفين:** حصاد + استنتاج نمط الشركة + توليد إيميلات محتملة.
- **أسماء وأدوار الموظفين:** من الشبكات المهنية + ميتاداتا المستندات.
- **النطاقات المزيّفة (Phishing):** كشف typosquatting المسجّل.
- **تسريبات GitHub/GitLab:** أسرار، مفاتيح، ملفات إعدادات مكشوفة.
- **المستندات العامة:** استخراج ميتاداتا (أسماء، برامج، مسارات داخلية).
- **الأصول السحابية:** S3 buckets / Azure blobs / GCP مفتوحة.
- **Google/Bing Dorks:** ملفات حساسة، لوحات دخول، وثائق مسربة.
- **الأرشيف (Wayback):** مسارات مخفية، endpoints، نقاط دخول قديمة.
- **إشارات Dark Web:** هل بيانات الشركة مذكورة في أسواق التسريبات؟
- **تسريبات بيانات الموظفين:** فحص إيميلاتهم في قواعد التسريبات.

### 📧 عند فحص إيميل (`argus scan ahmed@company.com`)
تسريبات البيانات · المواقع المسجّل فيها · أسماء مستخدمين مشتقة → حساباتها · Gravatar · مفاتيح PGP · ظهوره في Google Dorks و pastes و Dark Web · تحليل النطاق.

### 📱 عند فحص رقم (`argus scan +966501234567`)
تحليل كامل (الدولة، المشغّل، نوع الخط، المنطقة الزمنية) · المواقع المسجّل فيها · كل الصيغ الممكنة · ظهوره في المحركات والشبكات وتطبيقات المراسلة والتسريبات و Dark Web.

### 👤 عند فحص username (`argus scan johndoe`)
البحث عبر 3000+ منصة (sherlock/maigret) · استخراج البيانات المرتبطة · الربط بإيميلات/أرقام محتملة.

## 🛠️ كتالوج الأدوات — دليل مرجعي كامل

> لكل أداة: **الوظيفة** · **الفائدة لك** · **طريقة التحميل** · **طريقة التشغيل اليدوي** · **كيف يستخدمها Argus**.
> ملاحظة: داخل Argus لا تحتاج تشغيل أي أداة يدوياً — كلها تُدار تلقائياً. الأوامر اليدوية للمرجع والفهم فقط.

### 🌐 أدوات النطاقات والبنية التحتية

#### 1. theHarvester
- **الوظيفة:** يجمع إيميلات، نطاقات فرعية، مضيفين، عناوين IP من 50+ مصدر عام (محركات بحث، PGP، شهادات، شبكات مهنية).
- **الفائدة:** نقطة البداية لأي فحص دومين — يعطيك خريطة أولية سريعة للأصول والإيميلات.
- **التحميل:** `pipx install theHarvester`
- **التشغيل اليدوي:** `theHarvester -d company.com -b all`
- **داخل Argus:** موديول `external/theharvester.py` يشغّله ويطبّع مخرجاته إلى Entities (emails/subdomains/ips).

#### 2. OWASP Amass
- **الوظيفة:** أقوى أداة تعداد نطاقات فرعية (سلبي + نشط) + رسم خرائط ASN/CIDR والبنية التحتية.
- **الفائدة:** يكشف نطاقات فرعية عميقة لا تظهرها الأدوات الأخرى — تغطية شبه كاملة لسطح الهجوم.
- **التحميل:** `go install -v github.com/owasp-amass/amass/v4/...@master`
- **التشغيل اليدوي:** `amass enum -passive -d company.com`
- **داخل Argus:** موديول `external/amass.py`، يُشغّل passive افتراضياً، active في بروفايل `deep`.

#### 3. subfinder
- **الوظيفة:** تعداد نطاقات فرعية سلبي سريع جداً (من ProjectDiscovery).
- **الفائدة:** سرعة عالية لجمع النطاقات الفرعية من عشرات المصادر دفعة واحدة.
- **التحميل:** `go install -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest`
- **التشغيل اليدوي:** `subfinder -d company.com -all`
- **داخل Argus:** موديول `external/subfinder.py`.

#### 4. assetfinder
- **الوظيفة:** إيجاد النطاقات والأصول المرتبطة بدومين.
- **الفائدة:** يكمّل subfinder/amass بمصادر مختلفة لتغطية أوسع.
- **التحميل:** `go install github.com/tomnomnom/assetfinder@latest`
- **التشغيل اليدوي:** `assetfinder company.com`

#### 5. findomain
- **الوظيفة:** تعداد نطاقات فرعية فائق السرعة (Rust).
- **الفائدة:** أداء ممتاز على النطاقات الكبيرة.
- **التحميل:** تنزيل الثنائي من releases الرسمية.
- **التشغيل اليدوي:** `findomain -t company.com`

#### 6. dnsx
- **الوظيفة:** استعلامات DNS جماعية سريعة (resolve، حالة، أنواع سجلات).
- **الفائدة:** التحقق من حيوية النطاقات الفرعية بسرعة وجمع سجلاتها.
- **التحميل:** `go install github.com/projectdiscovery/dnsx/cmd/dnsx@latest`
- **التشغيل اليدوي:** `cat subs.txt | dnsx -a -resp`

#### 7. dnsrecon
- **الوظيفة:** فحص DNS شامل + محاولة zone transfer + brute force.
- **الفائدة:** يكشف سجلات وتهيئات DNS خاطئة قد تسرّب معلومات.
- **التحميل:** `pipx install dnsrecon`
- **التشغيل اليدوي:** `dnsrecon -d company.com`

#### 8. massdns
- **الوظيفة:** حل DNS جماعي فائق السرعة (C).
- **الفائدة:** لحل مئات الآلاف من الأسماء بسرعة في التعداد الكبير.
- **التحميل:** بناء من المصدر (`make`).
- **التشغيل اليدوي:** `massdns -r resolvers.txt -t A subs.txt`

#### 9. httpx
- **الوظيفة:** فحص خدمات HTTP الحية (حالة، عنوان، تقنيات، لقطات شاشة).
- **الفائدة:** يميّز الخوادم الحية من الميتة ويعطي بصمة تقنية سريعة.
- **التحميل:** `go install github.com/projectdiscovery/httpx/cmd/httpx@latest`
- **التشغيل اليدوي:** `cat subs.txt | httpx -title -tech-detect -status-code`

#### 10. naabu
- **الوظيفة:** فحص منافذ سريع (active).
- **الفائدة:** يكشف المنافذ المفتوحة على الأصول بسرعة قبل التعمّق.
- **التحميل:** `go install github.com/projectdiscovery/naabu/v2/cmd/naabu@latest`
- **التشغيل اليدوي:** `naabu -host company.com -top-ports 1000`

#### 11. nmap
- **الوظيفة:** فحص منافذ وخدمات تفصيلي + كشف الإصدارات + سكربتات.
- **الفائدة:** التحليل العميق للخدمات المكشوفة (يُستخدم في بروفايل `deep` فقط).
- **التحميل:** `sudo apt install nmap` / `brew install nmap`
- **التشغيل اليدوي:** `nmap -sV -sC company.com`

#### 12. WhatWeb
- **الوظيفة:** بصمة تقنيات المواقع (CMS، أطر، خوادم، مكتبات).
- **الفائدة:** معرفة ما بُني به الموقع → استهداف ثغرات التقنية.
- **التحميل:** `sudo apt install whatweb`
- **التشغيل اليدوي:** `whatweb company.com`

#### 13. wafw00f
- **الوظيفة:** كشف جدار حماية تطبيقات الويب (WAF).
- **الفائدة:** معرفة وجود WAF يوجّه أسلوب الفحص.
- **التحميل:** `pipx install wafw00f`
- **التشغيل اليدوي:** `wafw00f https://company.com`

#### 14. waybackurls / gau
- **الوظيفة:** استخراج الروابط التاريخية من Wayback Machine و Common Crawl.
- **الفائدة:** يكشف مسارات وملفات و endpoints قديمة قد تكون لا تزال حية.
- **التحميل:** `go install github.com/tomnomnom/waybackurls@latest`
- **التشغيل اليدوي:** `echo company.com | waybackurls`

#### 15. openSquat
- **الوظيفة:** كشف النطاقات المزيّفة (typosquatting) للعلامة التجارية.
- **الفائدة:** رصد محاولات التصيّد (phishing) ضد شركتك.
- **التحميل:** `git clone` + `pip install -r requirements.txt`
- **التشغيل اليدوي:** `python opensquat.py -k company`

### 📧 أدوات البريد الإلكتروني

#### 16. holehe
- **الوظيفة:** يكشف على أي المواقع/الخدمات يوجد حساب مسجّل بهذا الإيميل (بلا تنبيه للهدف).
- **الفائدة:** يرسم بصمة الحضور الرقمي للموظف عبر الإنترنت.
- **التحميل:** `pipx install holehe`
- **التشغيل اليدوي:** `holehe ahmed@company.com`

#### 17. h8mail
- **الوظيفة:** البحث عن الإيميل في تسريبات البيانات (وكلمات المرور المكشوفة).
- **الفائدة:** يكشف إن كانت بيانات الموظف مسرّبة — أولوية أمنية قصوى.
- **التحميل:** `pipx install h8mail`
- **التشغيل اليدوي:** `h8mail -t ahmed@company.com`

#### 18. mosint
- **الوظيفة:** جامع OSINT شامل للإيميل (تسريبات، DNS، مواقع مرتبطة).
- **الفائدة:** تقرير سريع متعدد المصادر عن الإيميل.
- **التحميل:** `go install github.com/alpkeskin/mosint/v3/cmd/mosint@latest`
- **التشغيل اليدوي:** `mosint ahmed@company.com`

### 📱 أدوات أرقام الهواتف

#### 19. PhoneInfoga
- **الوظيفة:** تحليل رقم الهاتف (المشغّل، الدولة، نوع الخط) + بحث في المحركات.
- **الفائدة:** أشهر أداة هاتف — نقطة ارتكاز لربط الرقم بحسابات وظهور عام.
- **التحميل:** تنزيل الثنائي من releases أو `docker run sundowndev/phoneinfoga`
- **التشغيل اليدوي:** `phoneinfoga scan -n +966501234567`

#### 20. ignorant
- **الوظيفة:** يكشف إن كان الرقم مسجّلاً في مواقع/خدمات (نظير holehe للهاتف).
- **الفائدة:** يربط الرقم بحسابات على منصات مختلفة.
- **التحميل:** `pipx install ignorant`
- **التشغيل اليدوي:** `ignorant 966 501234567`

#### 21. phonenumbers (libphonenumber)
- **الوظيفة:** تحليل/تحقق/تنسيق دولي للأرقام + المشغّل والمنطقة (يعمل offline بلا نت).
- **الفائدة:** أساس موثوق لتطبيع أي رقم قبل تمريره لبقية الأدوات.
- **التحميل:** `pip install phonenumbers`
- **الاستخدام:** مكتبة داخلية يستدعيها موديول `native_phone_enrich`.

### 👤 أدوات أسماء المستخدمين والحسابات

#### 22. Sherlock
- **الوظيفة:** البحث عن username عبر 400+ منصة اجتماعية.
- **الفائدة:** يرسم حضور الشخص عبر المنصات من اسم مستخدم واحد.
- **التحميل:** `pipx install sherlock-project`
- **التشغيل اليدوي:** `sherlock johndoe`

#### 23. Maigret
- **الوظيفة:** نسخة موسّعة من Sherlock — 3000+ موقع + استخراج بيانات الملف الشخصي.
- **الفائدة:** أعمق تغطية لأسماء المستخدمين + معلومات إضافية من كل ملف.
- **التحميل:** `pipx install maigret`
- **التشغيل اليدوي:** `maigret johndoe`

#### 24. WhatsMyName
- **الوظيفة:** قاعدة بيانات ضخمة (JSON) لفحص أسماء المستخدمين عبر المواقع.
- **الفائدة:** المصدر المرجعي الذي تعتمد عليه أدوات username الأخرى.
- **التحميل:** `git clone` (ملف بيانات).
- **الاستخدام:** يستهلكه موديول username الخاص بنا.

#### 25. socialscan
- **الوظيفة:** التحقق من توفّر/استخدام username وإيميل على المنصات.
- **الفائدة:** يميّز الحسابات المستخدمة فعلاً من غير المسجّلة.
- **التحميل:** `pip install socialscan`
- **التشغيل اليدوي:** `socialscan johndoe ahmed@company.com`

#### 26. blackbird
- **الوظيفة:** بحث سريع عن الحسابات بالاسم/username.
- **الفائدة:** بديل/مكمّل سريع لـ Sherlock.
- **التحميل:** `git clone` + `pip install -r requirements.txt`
- **التشغيل اليدوي:** `python blackbird.py -u johndoe`

### 🧰 إطارات وأدوات مساندة

#### 27. SpiderFoot
- **الوظيفة:** إطار OSINT آلي بـ 200+ موديول (يجمع كل شيء عن هدف).
- **الفائدة:** تغطية واسعة جداً كطبقة إضافية؛ نتكامل معه ونستهلك نتائجه.
- **التحميل:** `pipx install spiderfoot`
- **التشغيل اليدوي:** `sf.py -s company.com` (أو واجهة الويب).

#### 28. recon-ng
- **الوظيفة:** إطار استطلاع نمطي بأسلوب Metasploit.
- **الفائدة:** موديولات جاهزة قابلة للأتمتة.
- **التحميل:** `pipx install recon-ng`
- **التشغيل اليدوي:** `recon-ng` ثم تحميل الموديولات.

#### 29. Photon
- **الوظيفة:** زاحف ويب سريع يستخرج إيميلات، روابط، ملفات، بيانات من الموقع.
- **الفائدة:** حصاد داخلي من موقع الشركة نفسه.
- **التحميل:** `git clone` + `pip install -r requirements.txt`
- **التشغيل اليدوي:** `python photon.py -u https://company.com`

#### 30. ExifTool
- **الوظيفة:** استخراج بيانات الميتا من الصور والملفات.
- **الفائدة:** يكشف أسماء موظفين/برامج/أجهزة من ميتاداتا المستندات العامة.
- **التحميل:** `sudo apt install libimage-exiftool-perl`
- **التشغيل اليدوي:** `exiftool document.pdf`

#### 31. metagoofil
- **الوظيفة:** تنزيل مستندات المؤسسة العامة واستخراج ميتاداتا منها.
- **الفائدة:** حصاد جماعي للميتاداتا من كل مستندات الشركة المفهرسة.
- **التحميل:** `pipx install metagoofil`
- **التشغيل اليدوي:** `metagoofil -d company.com -t pdf,docx,xlsx`

#### 32. gitleaks / trufflehog
- **الوظيفة:** كشف الأسرار (كلمات مرور، مفاتيح API، توكنات) في المستودعات.
- **الفائدة:** كشف تسريبات شركتك على GitHub — من أخطر المخاطر.
- **التحميل:** `go install`/ثنائيات releases.
- **التشغيل اليدوي:** `trufflehog github --org=company` / `gitleaks detect`

#### 33. SearXNG (ذاتي الاستضافة)
- **الوظيفة:** محرك بحث محايد (meta-search) يجمع نتائج 70+ محرك عبر واجهة واحدة.
- **الفائدة:** ينفّذ Google Dorks **بلا CAPTCHA وبلا مفتاح** — العمود الفقري لمحرك الـ dorking.
- **التحميل:** `docker compose up` (ضمن مجلد `docker/searxng`).
- **الاستخدام:** يستدعيه موديول `native_dork_engine` عبر واجهته المحلية.

## 📊 التقارير

كل فحص يُنتج تقريراً موحّداً يحتوي:
1. **ملخص تنفيذي** — الهدف، عدد الكيانات، أبرز المخاطر.
2. **بطاقة الهدف** — كل ما اكتُشف مصنّفاً.
3. **جداول الكيانات** — نطاقات فرعية، إيميلات، حسابات، تسريبات، منافذ، تقنيات.
4. **رسم العلاقات** — من مرتبط بمن (بأسلوب Maltego).
5. **تقييم المخاطر** — 🔴 Critical / 🟠 High / 🟡 Medium / 🔵 Low / ℹ️ Info.
6. **الأدلّة** — مصدر ورابط وطابع زمني لكل معلومة (معتمد عليه 100%).
7. **التوصيات** — خطوات معالجة عملية.

الصيغ: `HTML` تفاعلي · `PDF` رسمي · `JSON` للتكامل · `Markdown` · `CSV` · `Graph`.

## ⚖️ الاستخدام القانوني والأخلاقي (اقرأه)

> **هذه الأداة مخصّصة للاستخدام المصرّح به فقط.**

- استخدمها **فقط** على أصول شركتك أو ما لديك **تفويض كتابي** بفحصه.
- الأداة **passive-first**: لا تلمس الهدف افتراضياً؛ الفحص النشط يتطلب إقراراً صريحاً.
- **Dark Web:** الأداة تبحث عن **إشارات التعرّض فقط** — **ممنوع منعاً باتاً** تنزيل أو شراء أو حيازة بيانات مسروقة.
- كل فحص يُسجّل في **سجل تدقيق** (audit log) للامتثال.
- النتائج قد تحوي بيانات شخصية حسّاسة — تُخزّن محلياً فقط، ولا تُرفع لأي سحابة.
- المستخدم وحده مسؤول عن الالتزام بالقوانين المحلية وشروط خدمة المصادر.
